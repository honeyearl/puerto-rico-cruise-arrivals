# Puerto Rico Cruise Arrivals

Passenger-only cruise arrival dashboard for San Juan, Puerto Rico.

## Coverage
- November 2026 through April 2027
- Cruise vessels only; Kydon ferry excluded
- Passenger figures are capacity-based planning estimates, not observed arrivals

## Deployment
This repository is intended for GitHub Pages.

## Data sources
- TheCruiseNexus for February–April 2027 departure schedules
- Previously loaded schedule data for November 2026–January 2027
- Operator guest capacity used for passenger planning estimates

## Status
Draft pending direct-source ingestion from cruise-line APIs or official itinerary pages.
